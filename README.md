# TravelGo – Travel Booking Mini Project

TravelGo is a travel booking web application developed using HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MySQL
* Nodemailer

## Features

* User Registration
* User Login
* Destination Viewing
* Travel Booking
* Password Reset through Email
* MySQL Database Connectivity

## Requirements

Install the following software:

* Node.js
* MySQL Server
* Git (optional)

## How to Run the Project

1. Clone or download this repository.

2. Open the project folder in Command Prompt or VS Code.

3. Install the required packages:

   ```bash
   npm install
   ```

4. Create the MySQL database named `travelgo_db`.

5. Configure your database and email settings in a `.env` file, using the variable names expected by `server.js`.

6. Create the required database tables before running the application.

7. Start the server:

   ```bash
   npm start
   ```

8. Open your browser and visit:

   `http://localhost:3000`

## Important Notes

* The `.env` file and database credentials are not included in this repository for security.
* The MySQL database and required tables must be configured separately.
* Email password-reset functionality requires valid email configuration.
* Payment functionality, if included, is for demonstration purposes only.
